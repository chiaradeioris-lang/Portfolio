il curriculum e una selezione di progetti realizzati durante il percorso

## Come avviare il progetto 		

Il progetto può essere aperto direttamente tramite index.html.

Per compilare il file SCSS in CSS è possibile utilizzare Sass con il comando:

```text
sass.cmd --watch assets/scss/style.scss:assets/css/style.css
```
